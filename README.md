# 🎮 Geometry Dash Clone (Web)

Полноценный клон легендарной игры **Geometry Dash**, написанный на чистом HTML, CSS и JavaScript (Canvas API). Игра работает прямо в браузере, не требует установки и сохраняет ваш прогресс локально.

🔗 **[Играть прямо сейчас!]https://github.com/AbuBread/GD-Clone/)**

---

## ✨ Особенности игры

*   **🎮 Классический геймплей:** Динамичные прыжки, смертельные шипы, блоки, батуты, орбы (сферы прыжков), вращающиеся пилы и даже порталы смены гравитации!
*   **🛠 Полноценный редактор уровней:** Создавай собственные уровни, расставляй препятствия (включая маленькие блоки), настраивай финиш и сохраняй творения.
*   **📜 Сюжетная кампания:** Узнай историю цифрового мира, восстанавливая логи системы по мере прохождения уровней.
*   **🛒 Внутриигровой магазин:** Зарабатывай монеты на уровнях и трать их на покупку эксклюзивных скинов.
*   **🏆 Система достижений:** Более 10 ачивок за разные действия (прыжки, смерти, сбор монет, создание уровней).
*   **🎨 Уникальные скины:** Все скины — это квадраты с уникальными цветами и текстурами (кресты, шахматки, полоски, глитч и т.д.), которые открываются за достижения или покупаются в магазине.
*   **💾 Сохранение прогресса:** Весь твой прогресс (рекорды, монеты, скины, созданные уровни) сохраняется в `localStorage` браузера.

## 🕹 Управление

| Действие | Клавиша / Мышь |
| :--- | :--- |
| **Прыжок** | `Пробел` / `W` / `Стрелка Вверх` / `ЛКМ` |
| **Пауза** | `Esc` |
| **Использование орба (в воздухе)** | Нажать кнопку прыжка рядом с орбом |
| **Редактор: Поставить объект** | `ЛКМ` (Левая кнопка мыши) |
| **Редактор: Удалить объект** | `ПКМ` (Правая кнопка мыши) |
| **Редактор: Прокрутка уровня** | `Колесо мыши` или стрелки `Влево`/`Вправо` |

---

## 🚀 Как запустить локально

Так как игра написана на чистом JavaScript без использования сборщиков, тебе достаточно:
1. Скачать файл `index.html` из этого репозитория.
2. Открыть его двойным кликом в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Играть!

*(Если ты хочешь использовать локальный сервер, можно запустить `python -m http.server` в папке с проектом).*

---

## 🛠 Технологии

*   **HTML5 Canvas** — для отрисовки графики, частиц и плавных эффектов.
*   **Vanilla JavaScript** — игровая логика, физика, обработка коллизий и редактор.
*   **CSS3** — стильный интерфейс меню, HUD и адаптивная верстка.
*   **LocalStorage API** — для сохранения прогресса игрока прямо в браузере.
